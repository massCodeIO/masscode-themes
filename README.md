# massCode Community Themes

Official community theme registry for [massCode](https://github.com/massCodeIO/massCode).

Browse, preview, install, update, and remove community themes in one click inside massCode via **Settings → Appearance → Community Themes**.

## Submit Your Theme (No Git Required)

1. Create and customize your theme in massCode (**Settings → Appearance → Create Theme Template**).
2. Click **Submit to Community** in **Settings → Appearance**, or open the [GitHub Web Theme Editor](https://github.com/massCodeIO/masscode-themes/new/main/themes) directly.
3. Click **Commit changes → Create pull request**.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for the full JSON schema and validation rules.

## Registry Format

`registry.json`, `previews/*.svg`, and the themes table above are auto-generated by GitHub Actions whenever changes in `themes/` are merged into `main`. Do not edit them manually.
